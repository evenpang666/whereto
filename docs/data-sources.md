# 数据来源与覆盖边界

当前项目的目标是可离线探索的中国旅行目录，并非完整官方景区库或实时旅游评价平台。

数据覆盖 34 个省级地区，391 个城市与地区：大陆地级市、自治州/盟/地区、直辖市及部分省直管县级地区，港澳，以及台湾 22 个市县。一个地区至少一处景点，较多景点来自有坐标的 5A 快照。当前总计 543 处，373 条来自 5A 数据、170 条为城市补充。不能把“每个收录城市有条目”等同于“全国所有景点已完备”。

## 必须区分的内容

| 字段 / 状态 | 含义 |
| --- | --- |
| `precision: scenic-reference` | 来源数据给出的景区代表点，可能是入口、中心或近似点，不是景区边界，也不保证入口导航精度。 |
| `precision: city-reference` | 景点名称已补充，但尚未核实坐标；显示城市中心，UI 显式标明。 |
| `imageKind: reference` | 缓存来源网页参考配图，不能据此认定实拍、实时或已取得再分发许可。 |
| `imageKind: ai-illustration` | 为当前景点单独生成的 AI 印象图，非现场照片；本地预置，浏览 $0。 |
| `imageKind: illustration` | 本地类别景观示意，非该景点实景外观。 |
| `detail.kind: dsh-agent` | 宿主 DSH Agent 生成的解读，包含会话、模型、时间、用量、来源和轨迹，不保证史实无误；旧缓存可能仍为 ai。 |
| `prose` | 景点散文邀约；本地类别文案或用户主动生成的 AI 文案，是旅行意境表达。 |
| `feedback` | 体验推测，单独分栏，不冒充真实口碑；本地卡片提供按类型编写的建议。 |
| `realReviews` | DSH Agent 会话中工具返回的亲历原文摘录，带平台与原文链接；reviewUrls 映射工具来源，reviewExcerpts 必须逐字匹配网页工具原文。无可核验摘录则省略。未核验发帖者身份，也不代表整体游客口碑。 |
| `weather` | Open-Meteo 当前模型天气与当日预报，按景点或城市参考坐标请求。独立更新，不使用 AI 推测或解读缓存。 |

部分景点限制进入或可能关闭，例如三沙地区、年保玉则等。基础卡片保留提醒，出行前应查当地官方信息。只对地图探索作出数据覆盖承诺，不对旅游可进入性作承诺。

台湾市级边界在所选 DataV 来源中缺失，省级视图提供明确市县点供选择；不是伪造的行政区多边形。城市中心仅为可交互的目录入口。

## 数据质量记录

当前 543 处景点均有本地配图：532 张网页来源参考图，11 张内置 imagegen 生成的独立景点印象图。AI 图片生成提示与文件映射见 [generated-scenery-prompts.json](generated-scenery-prompts.json)。它们是印象表达，不是建筑测绘或现场状态证明。

运行 `node scripts/audit-data.mjs` 重新生成 `data-audit.csv` 和 `data-coverage.json`。CSV 为逐景点清单，含城市、名称、坐标精度、图像类别、图源和资料页。应优先核实城市参考点、配图对应关系、历史背景与真实口碑来源。
