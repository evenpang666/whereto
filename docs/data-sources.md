# 数据来源与覆盖边界

当前项目提供可离线探索的中国与世界旅行目录，并非完整官方景区库或实时旅游评价平台。

数据覆盖 34 个省级地区，391 个城市与地区：大陆地级市、自治州/盟/地区、直辖市及部分省直管县级地区，港澳，以及台湾 22 个市县。一个地区至少一处景点，较多景点来自有坐标的 5A 快照。当前总计 543 处，373 条来自 5A 数据、170 条为城市补充。不能把“每个收录城市有条目”等同于“全国所有景点已完备”。

## 必须区分的内容

| 字段 / 状态 | 含义 |
| --- | --- |
| `precision: scenic-reference` | 来源数据给出的景区代表点，可能是入口、中心或近似点，不是景区边界，也不保证入口导航精度。 |
| `precision: city-reference` | 景点名称已补充，但尚未核实坐标；显示城市中心，UI 显式标明。 |
| `imageKind: reference` | 缓存来源网页参考配图，不能据此认定实拍、实时或已取得再分发许可。 |
| `imageKind: ai-illustration` | 为当前景点单独生成的 AI 印象图，非现场照片；本地预置，浏览 $0。 |
| `imageKind: illustration` | 本地类别景观示意，非该景点实景外观。 |
| `imageKind: unavailable` | 暂无可核实的当地照片，显示文字提示，不用虚构景观补位。 |
| `detail.kind: dsh-agent` | 宿主 DSH Agent 生成的解读，包含会话、模型、时间、用量、来源和轨迹，不保证史实无误；旧缓存可能仍为 ai。 |
| `prose` | 由 DSH Web 会话根据景点资料撰写的散文邀约，用户主动生成并缓存；属于旅行意境表达。 |
| `feedback` | 体验推测，单独分栏，不冒充真实口碑；本地卡片提供按类型编写的建议。 |
| `realReviews` | DSH Agent 会话中工具返回的亲历原文摘录，带平台与原文链接；reviewUrls 映射工具来源，reviewExcerpts 必须逐字匹配网页工具原文。无可核验摘录则省略。未核验发帖者身份，也不代表整体游客口碑。 |
| `weather` | Open-Meteo 当前模型天气与当日预报，按景点或城市参考坐标请求。独立更新，不使用 AI 推测或解读缓存。 |

部分景点限制进入或可能关闭，例如三沙地区、年保玉则等。基础卡片保留提醒，出行前应查当地官方信息。只对地图探索作出数据覆盖承诺，不对旅游可进入性作承诺。

台湾市级边界在所选 DataV 来源中缺失，省级视图提供明确市县点供选择；不是伪造的行政区多边形。城市中心仅为可交互的目录入口。

## 数据质量记录

当前 543 处景点均有本地配图：532 张网页来源参考图，11 张内置 imagegen 生成的独立景点印象图。AI 图片生成提示与文件映射见 [generated-scenery-prompts.json](generated-scenery-prompts.json)。它们是印象表达，不是建筑测绘或现场状态证明。

运行 `node scripts/audit-data.mjs` 重新生成 `data-audit.csv` 和 `data-coverage.json`。CSV 为逐景点清单，含城市、名称、坐标精度、图像类别、图源和资料页。应优先核实城市参考点、配图对应关系、历史背景与真实口碑来源。

完整来源、版权和许可见 [credits.md](credits.md)。开发及更新流程见 [development.md](development.md)。

## 世界目录与各国层级

世界底图为 Natural Earth 1:50m Admin-0，含 238 个国家与地区地图单元（不是主权国家数量）；不单独展示南极。中国使用现有 DataV 边界及目录，世界模式与中国模式共用其省市和景点 ID。其他国家与地区的区划来自 Natural Earth 1:10m Admin-1，按国家单独保存在 `public/data/maps/world/`，进入国家时按需读取。

新增目录含 1110 个城市与目的地区域、168 处具体景点和 1071 个城市漫步入口。具体景点覆盖 55 个国家，包含美国 67 处（50 州及华盛顿特区均有具体条目）、俄罗斯 27 处（20 个联邦主体）。美国、俄罗斯优先补齐每个区划在 Natural Earth 中可取得的代表城市，避免大国区划只有空白入口。按国、按区划的具体景点、城市漫步与照片数量见 [world-data-coverage.json](world-data-coverage.json)。

城市坐标来自 Natural Earth；景点实体与坐标来自 Wikidata CC0 或 Wikipedia 公开位置数据，不复制百科正文。策划清单保存在 `scripts/data/world-destinations.tsv`（含已核对 QID），核验后的事实、图源和许可保存在 `public/data/world-landmarks.json`。对同名建筑使用具体 QID，雅罗斯拉夫尔教堂固定为 Q4177920；索洛韦茨基修道院的阿尔汉格尔斯克州归属另附 UNESCO 官方来源。坐标为代表点，不是入口导航。

原有“距城市超过 35 公里就丢弃”的限制已移除。景点优先与所在区划中的城市关联，12–120 公里内的附近城市会明确标为参考分组和直线距离，不表示实际交通路线；超过 120 公里或缺少合适城市的景点创建 `kind: destination-area` 目的地区域，不伪造城市、不挂靠数千公里外的城市。贝加尔湖等跨地区目的地附单独说明。城市漫步仍是城市探索入口，不能当作已经核实的具体景区。

具体景点均有本地参考照片，保留作者、原始文件页、作品日期（可得时）、许可及额外署名要求。城市漫步使用当地照片或同城已核实地标照片，注明参考画面；城市实体由 Natural Earth 完整城市数据的 Wikidata ID 匹配，并以坐标交叉检查，不能只按同名字符串配图。排除地图、旗帜、徽章、绘画及不适合作为城市画面的素材。少数没有可靠实景来源的入口显示“实景照片待补充”，不再使用 SVG 类别示意。

逐图记录见[景点照片署名](world-photo-credits.md)与[城市照片署名](world-city-photo-credits.md)，最新覆盖及缺图条目见 [world-photo-coverage.json](world-photo-coverage.json)。城市照片清单位于 `public/data/world-city-photos.json`，重建目录时会保留。照片保持各自许可，不纳入项目代码 MIT 授权。

每个国家有独立的 `regionLabel`、`hierarchyNote` 和区划数据。特别处理日本都道府县、美国州／联邦区、加拿大省／地区、澳大利亚州／领地、瑞士州、德国联邦州、泰国府、韩国道／广域市、印度邦／中央直辖区等；法国和意大利按来源的 `region` 归并省级多边形，英国按 `geonunit` 归并四个构成国。新加坡、摩纳哥、梵蒂冈及缺少区划数据的小型地区直接进入城市。其他国家显示其来源中的一级行政区，不推断不存在的统一省制。区划是来源快照，可能与最新调整存在差异；尚未收录城市的区划显示为空，地图边界与城市或地标目录的覆盖分别说明。

世界地图对各多边形独立校正环方向，聚焦视角按主要陆地拟合，国家视角使用经度旋转以处理日期变更线。海外地区、飞地和岛屿可从区划列表独立进入。基础目录、地图与图片均在本地，浏览不访问第三方地图或图片服务器。天气单独按 Open-Meteo 返回的目的地 IANA 时区、UTC 偏移和当地日期校验，跨午夜不会用北京时间误判过期。所有世界条目另预置由 geo-tz 边界查询或人工核验取得的 IANA 时区，用于天气离线时的当地完整日期与实时时钟。Intl 根据对应时区计算夏令时；无法取得可靠时区时不默认使用北京时间。
