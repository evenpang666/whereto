# 排错指南

## 端口与浏览器

默认端口 3789。重复双击启动脚本会检查 `/api/health`，只复用返回 `app: whereto` 的实例。其他程序占用时，不自动终止它。

PowerShell：

```powershell
$env:PORT = '3790'
npm run launch
```

Linux：

```bash
PORT=3790 bash start.sh
```

开发模式 Vite 的代理固定指向 3789，修改后也要同步 `vite.config.js`。浏览器打不开时确认启动窗口仍在、地址正确，并让代理绕过 `localhost` 和 `127.0.0.1`。不要将服务改为公网监听以解决本机问题。

## Windows 双击

安装 Node 后通常需要新开终端，旧终端不会自动更新 PATH。路径含空格时仍应从根目录 `start.bat` 启动。首次运行会联网安装；失败日志保留在窗口，可以在该目录手动运行 `npm ci`。不要双击源码 `index.html`，它需要构建和本地 API 服务。

批处理文件应保留 CRLF 换行；项目的 `.gitattributes` 已设置。如果编辑器把它改成 LF，部分 Windows `cmd` 会把命令错误地拆开，出现 `d` 等命令无法识别的提示。请将 `start.bat` 转回 CRLF 后重试。

## 手机与局域网

启动后，主页底部与启动窗口显示以太网的 `http://192.168.x.x:3789` 地址。手机接入同一路由器的 Wi-Fi，直接输入该地址；手机上的 `127.0.0.1` 指向手机本身，不能访问电脑。主机保持启动窗口运行。路由器的访客网络或 AP 隔离可能阻止设备互访。

程序只选 192.168 开头的以太网；Wi-Fi、VMware、VPN 网卡不会被作为分享地址。如果没有符合条件的接口，主页会说明当前仅支持本机。IP 随路由器重新分配而变化时，重启服务以读取新地址。Linux 常见接口名 eth0、eno1、enp3s0 均支持。

Windows 防火墙提示时，为 Node.js 允许“专用网络”。如没有提示，在“Windows Defender 防火墙 → 允许应用通过防火墙”中检查 Node.js 的专用网络权限；也可以由管理员创建仅允许本地子网访问 TCP 3789 的入站规则。不要关闭整个防火墙。Linux 如启用 ufw/firewalld，也需按本地子网开放所选端口。

项目提供 `enable-lan.bat`，双击并接受 Windows 管理员授权，会创建或更新 `Whereto-LAN-3789` 规则：仅 Node.js、TCP 3789、所选以太网、本机 192.168 地址与其同一子网。公用/专用网络配置均可使用，远程地址仍严格限制为该以太网子网。换 IP 或更换 Node 安装位置后重跑即可。自定义端口用 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/enable-lan.ps1 -Port 3790`。如需撤销，在高级防火墙设置中禁用/删除对应名称的规则，或在管理员 PowerShell 执行 `Remove-NetFirewallRule -Name Whereto-LAN-3789`。

局域网设备共享记录与主机的 DSH Agent 能力，适合自己的可信局域网。漫游会话偏好只能在主机 `127.0.0.1` 页面修改；模型、密钥、工具、skills 和权限在 DSH Web 管理。项目不提供公网账户。

## 去过与批量匹配

“旅途足迹”表示最近点开过的景点，“去过”表示明确标记到访，互不等同。手动标记与撤销均免费；去过会让景点卡片和地图标记变灰，同时保留原有收藏。

批量输入可以使用逗号、换行或自然语言。同名景点尽量提供省市；只写城市不会自动标记整个城市。未对应或有歧义的名字单独显示。DSH 结果需自行核对，错误卡片可点击“已去过 · 撤销”。相同输入、目录、会话配置和业务 skill 可复用匹配缓存；新匹配按宿主 DSH 用量计费。

## Linux 双击

`chmod +x start.sh start.desktop` 后，GNOME/KDE 等桌面可能要求右键允许启动。`start.desktop` 通过 `%k` 定位它所在的项目目录，不能单独移动到别处；可建立快捷方式，或使用终端 `bash /项目绝对路径/start.sh`。没有 `xdg-open` 或默认浏览器时，手动打开启动窗口提供的地址即可。文件管理器自身策略可能禁止双击执行脚本，终端方式不受影响。

## AI 请求

- “未连接 DSH Agent”：使用 `start.bat` / `npm start` 启动；若已在其他终端运行 DSH Web，先运行 `npm run dsh:install` 并重启该宿主。直接 `node server/index.mjs` 只提供离线探索。
- 模型、密钥、余额或限流错误：打开 DSH Web 对应会话查看上游原因，在 DSH 的模型设置修正；漫游不再有独立 API Key 输入框。
- 预设没有搜索/skill 工具：在 DSH Web 调整该预设，或在漫游设置选择已有的标准/自定义研究预设；漫游不会绕过宿主工具权限。
- 参考会话错误：确认 ID 正确且属于当前 DSH_HOME，也可清空 ID 改用宿主默认模型和预设。
- 权限阻塞：在对应 DSH 会话处理工具或权限请求。漫游保留原缓存，不自动重复提交收费任务。
- 超时、取消或 JSON 格式错误：对应 DSH 会话和已知用量仍保留，已有缓存不受影响。支持15分钟等待窗口，可在卡片取消任务。会话完成后可点“读取已完成的会话结果”，重新校验回填，不再次调用模型。
- DSH Web 无法直接打开：使用启动窗口打印的 DSH 登录链接完成认证；漫游不向卡片或局域网返回宿主登录 token。

常规 `npm test` 使用会话替身，不消耗模型额度；真实宿主验证范围见 docs/verification.md。

## 本地资料

备份 `.local/` 后可恢复配置、心愿和手记。配置损坏时应用会显示错误，检查对应 JSON 或恢复备份。若仅想重置 AI 生成缓存，可停止服务后将 `.local/details.json` 改名备份；不要删除 `.local/usage.json`，以免失去已知费用记录。不要分享含密钥的 config 文件。

景观示意不是图片加载故障。地图中部分景点使用城市参考点。台湾使用城市点选择，因为当前 GeoJSON 来源缺少台湾市级边界。真实评价来自当前 DSH 会话搜索工具返回的结构化摘录；没有可引用结果时不伪造评分或评论。
