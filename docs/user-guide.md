# 使用指南

[返回首页](../README.md) · [安装与启动](getting-started.md) · [排错指南](troubleshooting.md)

## 从地图出发

点击省份、城市和景点标记，逐层探索；也可以直接搜索城市或景点。类型筛选支持山野、湖海、古迹和城市漫步。

“随心出发”在当前省市与类型筛选范围内随机选择一处景点。各级地图保留收藏爱心，视野外的收藏停靠在边缘，点击可前往。

当前目录收录 391 个城市与地区、543 处景点，每个收录城市至少一处。配图、坐标精度和资料核对情况见 [数据来源与边界](data-sources.md) 与 [逐条检查表](data-audit.csv)。景区代表点和城市参考点均不作为入口导航。

## 读一张旅行卡片

卡片包含基础介绍、推荐季节、停留时长，以及以下内容：

| 内容 | 阅读方式 |
| --- | --- |
| 散文邀约 | 点“生成散文简介与解读”，由 DSH 根据当前景点资料撰写并缓存。 |
| 风景背后的故事 | 浅米色框，展示景点背景与历史；传说和史实应区分。 |
| 游客反响 | 浅绿色框，分别展示体验推测和有原文出处的公开评价摘录。 |
| 旅行灵感 / DSH 旅行手记 | 浅蓝紫色框，说明看点、取舍与旅行建议。 |
| 出发前的小事 | 浅杏色框，集中展示实用提示。 |

未生成时，基础资料和本地旅行建议仍可阅读；散文区显示生成入口。已有 AI 内容可点“联网更新解读”重新撰写。更新会产生新的模型和工具用量。

### 天气

打开卡片时，Open-Meteo 提供当地天气，独立缓存 15 分钟。卡片展示气温、温差、降水概率等信息，并配有晴朗、夜晚、多云、雨、雷暴、雪和雾的氛围效果。城市参考点会标明天气参考位置；获取失败时可手动重试。

### 评价与来源

DSH Agent 根据预设工具检索公开网页、小红书和知乎。平台登录、访问或索引限制可能导致没有可引用结果，可使用卡片的平台检索链接继续查看。

“体验推测”是旅行建议；“真实评价”只展示工具返回、能与原文核对的亲历摘录，附来源链接，但不核验发帖者身份。无法核对、缺少来源或格式异常的条目单独略过，保留其余解读，并显示略过数量。

链接匹配兼容同一网页的片段锚点等 URL 写法差异。完整搜索摘要和多次网页读取的校验文本仅在内存中使用，不写入卡片缓存。

## 心愿、最近探索与去过

- 点“我想去这里”收藏，再点可取消。记录保存在主机，刷新或重启后仍在。
- “旅途足迹”记录最近点开的景点，不等于已经去过。
- 点“标记去过”，卡片和地图标记变灰；再次点击可撤销，收藏仍保留。
- “标记去过的风景”支持粘贴旅行记录，由 DSH Agent 匹配本地目录。歧义和未匹配名称单独列出，请核对后使用。

手动标记不调用模型。相同旅行记录可复用匹配缓存；新匹配按 DSH 与模型服务商的规则计费。

## DSH 会话与生成

默认沿用 DSH 宿主模型与 Agent 预设，也可在“本地设置”选择已有预设，或填写参考会话 ID。每次生成创建独立旅行会话，只沿用参考会话的模型与预设，不向参考会话发送消息。

生成时可查看工具进度、打开对应 DSH 会话或取消任务。会话和已报告用量保留在 DSH 与本地记录中；失败不会覆盖原景点缓存，也不自动重复提交生成请求。

界面保留任务会话 ID 时，可点“读取已完成的会话结果”重新校验并回填，无需再次生成。权限阻塞、模型凭据或搜索工具问题，应在对应 DSH 会话处理。

## 手机与局域网

手机连接同一路由器后，打开主页底部或启动窗口显示的局域网 URL，主机保持服务运行。应用选择 192.168 开头的以太网地址，排除 Wi-Fi、VMware、VPN 等接口；没有符合条件的网卡时仅提供本机地址。

局域网设备共享主机的收藏、去过记录和 DSH Agent 能力。会话偏好只能从主机 `127.0.0.1` 页面修改，DSH Web 的认证和监听设置由 DSH 管理。

Windows 防火墙阻止连接时，可运行 `enable-lan.bat` 并接受管理员授权；它仅对所选以太网、本地子网和应用端口放行。主机 IP 更换后可重新运行。具体排查和撤销方法见 [手机与局域网排错](troubleshooting.md#手机与局域网)。

## 数据、凭据与费用

收藏、足迹、设置和生成缓存保存在 `.local/`。备份其中的 JSON 文件即可保留业务数据；`.local/runtime/` 是可重新安装的运行环境，可排除在备份外。文件说明见 [架构与存储](architecture.md#数据与天气)。

模型密钥由 DSH 管理，不传入地图前端。旧版 `.local/config.json` 可能仍留有已停用的密钥，在新设置页保存后会写成仅包含会话偏好的格式；不要分享旧配置或 DSH 凭据目录。

浏览已缓存的卡片不会再次调用 Agent。主动生成、更新解读与新的足迹匹配会产生用量；漫游记录 DSH 已报告的输入、输出 tokens，不保证覆盖全部辅助工具费用，也不承诺固定单次美元上限。实际计费以 DSH 和上游服务为准。
