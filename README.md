![漫游whereto](public/brand/banner-roam.svg)

把好奇心交给地图。漫游whereto是一个 **DSH Web 业务插件**：保留中国旅行地图与景点卡片，生成和足迹匹配由宿主 DSH Agent 会话执行，复用其模型、工具、skills、权限和上下文管理。点开省份与城市，遇见一处风景；也可以随机出发，把想去的地方收藏起来。

地图与基础景点资料随项目提供；浏览、搜索、随机探索、收藏和足迹不需要 API Key。景点卡片包含粗楷体散文邀约、当日当地天气与随天气变化的动画。联网 AI 解读先查询网页、小红书、知乎，再补充景点故事、建议和附原文链接的游客评价，生成后保存在本机。

## 环境配置

- Windows 10/11、Linux 桌面；安装 [Node.js 22 或更新版本](https://nodejs.org/)、DSH CLI 和 pnpm（DSH 插件管理使用）。已在 DSH `0.1.5-rc.1` 的 Web profile 实测。
- 首次安装依赖需要联网；后续本地浏览可离线使用。生成使用 DSH Web 中已配置的模型与凭据，漫游不再独立调用模型 API 或设置 token 上限。
- 主机地址为 `http://127.0.0.1:3789`；同一局域网设备使用主页底部的小字 URL（自动选择 192.168 开头的以太网，排除 VMware、VPN 等虚拟网卡）。

## 快速使用

**Windows：** 双击根目录的 **`start.bat`**。首次准备依赖和构建，通过 `dsh plugin --profile web add link:项目目录` 注册整个项目，随后启动现有 DSH Web profile 和地图。已有插件、模型与 skills 保留。关闭启动窗口或按 `Ctrl+C` 停止本次启动的服务。若旧 DSH Web 已在运行但尚未加载漫游，先关闭并重新启动它。

**Linux：** 首次运行 `chmod +x start.sh start.desktop`。支持的桌面环境可双击 `start.desktop` 并选择“允许启动”，或将 `start.sh` 设为“作为程序运行”。不同文件管理器对可执行文件的双击行为不同，也可直接执行：

```bash
bash start.sh
```

也可以在 Windows / Linux 终端运行：

```bash
npm ci
npm run launch
```

1. 点击地图省份 → 城市 → 景点标记；也可搜索城市、景点或点击“随心出发”。随机范围跟随当前省市与类型筛选。
2. 在景点卡片点“我想去这里”，各级地图会保留爱心标记，视野外的收藏停靠在边缘，点击可前往。收藏与最近探索保存在主机，刷新或重启后仍在。
3. 在景点卡片点“标记去过”，卡片与标记变灰，可再次点击撤销。主页“标记去过的风景”支持粘贴旅行记录，交由 DSH Agent 对应库内卡片；歧义和未对应名称单独列出。手动标记免费，相同内容可复用缓存。
4. 在 DSH Web（默认 `http://127.0.0.1:3080`）管理模型、工具和 skills。漫游“本地设置”默认沿用宿主模型与默认 Agent 预设，也可填已有 DSH 会话 ID 沿用其模型和预设，或选择现有预设。每次生成创建独立旅行会话，不向参考会话发送消息。生成中可查看工具进度、打开 DSH Web 或取消任务；会话和结果保存在 DSH 与本地缓存中。
5. 天气由 Open-Meteo 提供，打开卡片自动获取，15 分钟更新，显示温度、当日温差、降水概率等；天气背景支持晴朗、夜晚、多云、雨、雷暴、雪与雾。城市参考点会标明天气位置。离线或获取失败时可重试，不显示虚构天气。
6. “游客反响”分为体验推测和真实评价。真实评价仅引用搜索返回的亲历原文摘录，附平台与原文链接；不核验发帖者身份。社交平台登录、访问或索引限制可能导致无可引用结果，此时可通过平台检索入口继续查看。

局域网设备共享主机的收藏、去过记录和 DSH Agent 能力；会话偏好只能从主机的 `127.0.0.1` 页面修改。手机需连接同一路由器，主机需保持服务运行。DSH Web 的认证和监听设置仍由 DSH 管理。

Windows 若阻止手机连接，双击 **`enable-lan.bat`** 并接受系统管理员授权。它仅对所选以太网、本地子网和本应用端口放行；不会关闭防火墙。更换主机 IP 后可重新运行。

漫游的新配置只保存参考会话和预设偏好。密钥由 DSH 管理，不传入地图前端。旧版 `.local/config.json` 可能仍留有原密钥，已经不使用；在新设置页保存后会写成新的偏好格式。请勿分享旧配置或 DSH 的凭据目录。

模型用量和工具执行由 DSH 管理；漫游记录会话已报告的输入/输出 tokens，不再声称固定单次美元上限，亦不将未知费用显示为 $0。再次浏览缓存不调用 Agent；主动更新会产生新的模型及工具用量。

## 数据范围

当前目录覆盖 **391 个城市与地区、543 处景点**，每个收录城市至少一处，全部景点均有本地图片：532 张来源参考配图和 11 张明确标注的 AI 景点印象图。基础资料来自公开数据与本地编辑，属于可继续补充的旅行目录。170 处点位仍为城市参考位置，**不宣称已完成全国所有景点的实景照片、精确入口坐标或真实游客口碑核验**。具体覆盖和待核对项目见 [数据来源与边界](docs/data-sources.md) 及 [逐条数据检查表](docs/data-audit.csv)。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 双击后提示找不到 Node.js | 安装 Node.js 22+ 后重新打开启动脚本。 |
| 首次安装失败 | 确认 npm 可联网，在项目目录运行 `npm ci` 后重试。 |
| 网页打不开 | 使用启动窗口显示的 `127.0.0.1` 地址；不要直接双击 `index.html`。检查代理是否绕过本地地址。 |
| 手机打不开 | 使用主页显示的以太网地址，手机连接同一局域网；检查 Windows 防火墙是否允许 Node.js 的专用网络入站，参考 [排错指南](docs/troubleshooting.md)。 |
| 端口被占用 | 同一应用重复启动会打开已运行页面；其他程序占用时，参考 [排错指南](docs/troubleshooting.md) 修改 `PORT`。 |
| AI 返回 401 / 402 / 429 | 在 DSH Web 检查模型凭据、余额或请求频率。错误不会覆盖原缓存，也不会自动重试。 |
| DSH 生成失败或需授权 | 打开任务对应的 DSH 会话处理模型、工具或权限问题；原卡片缓存保留。 |
